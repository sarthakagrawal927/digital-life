# Digital Life

Follow ../AGENTS.md. This is a research experiment, not an intelligence benchmark.
Use Node 24+ and pnpm. No runtime dependencies. The browser and runner share src/engine.mjs.
Run `pnpm test` for deterministic execution, accounting, mutation, snapshot, and experiment checks.
Organisms must never execute host code. Keep integer accounting and explicit hard bounds.
Do not commit, push, deploy, or release without explicit authorization.
